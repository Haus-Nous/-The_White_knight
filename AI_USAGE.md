# AI Usage Declaration

This project was built with assistance from AI tools in accordance with hackathon transparency guidelines:

- **Development & Orchestration**: [Claude Code](https://docs.anthropic.com/en/docs/agents-and-tools/claude-code/overview) (by Anthropic) was used as an AI development assistant for architecture planning, code generation, refactoring, and debugging using a Spec-Driven Development workflow.
- **Runtime AI Integrations**: The application dynamically connects to AI model providers (including Together AI, Anthropic Claude, and OpenAI APIs) via a configurable backend client to power key features such as job description parsing, ATS fit scoring, resume customization, company research, and interactive form Q&A generation.
